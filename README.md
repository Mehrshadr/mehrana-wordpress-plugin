# Mehrana App - WordPress Plugin

Headless SEO & Optimization Plugin for Mehrana App - Link Building, Image Optimization & More

## Features
- 🔗 Automated internal link building
- 🖼️ Image optimization
- 🔌 REST API for headless integration
- 📊 Works with Elementor & Gutenberg

## Installation
1. Download the latest release
2. Go to WordPress Admin → Plugins → Add New → Upload Plugin
3. Activate the plugin
4. Configure API key in Settings → Mehrana App

## Auto-Updates
This plugin supports automatic updates via GitHub releases.

## Requirements
- WordPress 5.0+
- PHP 7.4+
